# 56 Merge Intervals

**Link:** [LeetCode](https://leetcode.com/problems/merge-intervals/description/)  
**Difficulty:** Medium

## Approach
Two Pointer + Greedy

---

**Time Complexity:** O(nlogn)  
**Space Complexity:** O(n) 

## Key Learning
When problems require you to choose the at instance best result and the working array is sorted then we don't look back at the processed results. This is how we solve greedy questions.
